# Timbn.GraveyardKeeperTwo.CampfireMeditation

Timbn Campfire Meditation is retired since 1.5.0. Graveyard Keeper 2 1.012 added a campfire bench rest at the Keeper's house, so the plugin is empty and exists only so installed copies stop adding their own `Meditate` action. The text players see comes from `docs/CampfireMeditation/page.yml`.
